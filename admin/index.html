Kontagious Admin

Sign in to add events, blog posts and photos. Nothing is saved to the website until you press Publish.

How do I get a token?
  1. Sign in to GitHub with the account that owns the website.
  2. Open github.com/settings/personal-access-tokens/new.
  3. Name it "Kontagious admin" and set the expiration (1 year is the longest).
  4. Under Repository access, choose Only select repositories and pick kontagious-website.
  5. Under Permissions → Repository permissions, set Contents to Read and write.
  6. Click Generate token, copy it, and paste it above.

The token works like a password for this one website. Keep it private, and use Sign out on shared computers.
